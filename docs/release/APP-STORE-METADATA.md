## 3. 关键词(≤100 字符,逗号分隔,不重复 App 名)

推荐串(当前 67 字符,留有余量):

```text
阅读器,epub,电子书,读书,读书笔记,划线,反思,日记,AI,思考,记忆,个人成长,书架,高亮,专注,摘抄,读后感
```

策略:

- 不含竞品名与平台商标(微信读书、Kindle、ChatGPT 等一律不用);
- 不含「页外/余思」本身(名称已索引);
- 覆盖三类检索意图:格式与阅读(epub/阅读器/电子书)、行为(读书笔记/划线/摘抄)、差异化(反思/思考/记忆/AI/读后感);
- 上架后依据搜索表现迭代;每次改动随版本提交。

## 4. 描述(≤4000 字符;直接粘贴使用)

```text
[APP_NAME] 是一个以阅读为入口的思考工具:本地优先的 EPUB 阅读器,加上一位愿意认真听你说话的阅读伙伴。

它不希望你"读得更多",而是希望你读完之后,脑子里留下的东西多一点。

■ 一个完整的 EPUB 阅读器
导入你自己拥有的 EPUB(无 DRM),分页阅读、调节字号与行距、明暗主题、章节导航、书内搜索、进度记忆、划线与批注。没有网络也一切可用,不登录任何账号。

■ 读完之后,1–3 分钟输出
结束阅读时,你可以按住说一段,或写几句。它不要求你写正式读书笔记——刚读完时脑子里真实的想法,才是最有价值的。

■ 一位克制的阅读伙伴(需要你自己的 AI Key)
它会先理解你刚刚读了什么,再回应你的想法:有时澄清,有时追问,偶尔反驳,并连接你过去读过的书与说过的话。引用了你的旧想法时,可以点回原文与出处。
AI 功能采用 BYOK:在设置里选择服务商(OpenAI、Anthropic、DeepSeek、Gemini 等,或任意 OpenAI 兼容地址),填入你自己的 API Key。请求从你的设备直接发往该服务商。

■ 你的记忆,你说了算
它会慢慢记住你的观点、偏好和悬而未决的问题——全部只保存在你的设备上。每一条记忆都能查看、修改、删除;你的原始表达永远优先展示,不会被 AI 改写。

■ 数据完全属于你
书籍、进度、划线、反思、日志与记忆全部只存在本机;API Key 仅存于 iOS 钥匙串;每次 AI 请求只发送完成该请求所必需的少量上下文,不发送整本书,也不附带无关历史。你可以一键导出全部数据,或一键清除所有本地数据。没有我们的服务器,没有账号,没有追踪。

适合的人:有阅读习惯、愿意在读完之后想一想的人;想让自己的观点随时间留下痕迹的人。

注意:AI 反馈功能需要用户自备所选 AI 服务商的 API Key(在服务商官网申请),并可能产生该服务商的费用;不配置 Key 时,本应用仍是一个完整好用的 EPUB 阅读器。
```

> 注:文中 `[APP_NAME]` 在命名定案后替换;品牌词仅出现一次,改名成本最低。

画面清单(建议顺序,全部使用真机/模拟器真实界面,不得使用虚构的 AI 输出):

1. **书架**:有 2–3 本书,展示封面、进度与统计(阅读时长/划线/反思数);
2. **阅读器(日间)**:正文 + 划线浮层(长按选中),体现版式设置入口;
3. **阅读器(夜间或章节/搜索)**:二选一,展示主题与导航;
4. **Session 结束 → Reflection**:「按住说 / 写一点 / 今天先不了」的低摩擦界面;
5. **Agent 反馈 + 引用**:真实模型输出(真机 BYOK 跑出),含可跳转的证据/引用;
6. **Journal**:What I said(原始表达)/ What I think 结构;
7. **My Mind**:记忆列表与「AI 眼中的我」画像(体现可修改/删除);
8. **设置 → 数据与隐私**:导出与「清除所有本地数据」入口(呼应隐私主张)。

备注:第 5 张必须用真实服务商产出(可借用 bench 流程或真机跑一次);截图内不要出现真实 API Key、真实人名或可识别个人数据。
