「页外」(以下称"本 App")是一款以阅读为入口的个人思考工具:本地优先的 EPUB 阅读器,配合你自己配置的 AI 服务(BYOK,Bring Your Own Key)与运行在你设备上的本地 Agent。

本政策如实描述本 App 对你的数据做什么、不做什么。我们尽力用平实的语言写清楚;如有疑问,欢迎通过上方联系方式询问。

## 一、你的数据保存在哪里:全部仅保存在你的设备上

以下数据**只保存在你设备的本地存储中**,我们没有任何服务器来接收它们:

- 你导入的 EPUB 书籍文件;
- 阅读进度与阅读位置;
- 阅读会话记录(时长、起止位置);
- 划线(Highlight)与批注(Note);
- 你说出的或写下的反思(Reflection)及其转写文本;
- 与 Agent 的对话记录;
- 阅读日志(Journal);
- Agent 为你沉淀的长期记忆(Memory)与「AI 眼中的我」读者画像;
- 为本地检索建立的全文/向量索引;
- 阅读偏好、连读与思考连续记录、成就;
- 本地诊断与请求追踪记录(仅用于你在设置中自查)。

## 二、API Key 的存储

使用 AI 功能需要你自行配置 AI 服务商的 API Key(BYOK)。

- API Key **只保存在 iOS 钥匙串(Keychain)中**,并标记为"仅本设备、解锁时可用";
- API Key 不会写入数据库、不会写入偏好设置文件、不会出现在日志中;
- 数据库中只保存"Key 存放于钥匙串"的引用,不保存 Key 本身;
- 你可以随时在设置中删除 Key,或在「清除所有本地数据」时一并删除。

## 三、哪些数据会离开你的设备

**平时:没有。** 阅读、划线、写反思、记笔记、查看历史,全部在本地完成,不需要网络。

**只有一种情况**会有数据离开设备:你配置了自己的 AI 服务商,并主动触发一次 AI 请求(例如提交反思后获取 Agent 反馈,或发起一次讨论)。

此时,本 App 会把完成这次请求所**必要**的上下文发送到你**自己选择的服务商地址**:

- 你当前阅读位置附近的一小段原文;
- 从当前书中检索出的少量相关段落摘录;
- 与本次讨论相关的、你自己过往的反思或记忆片段(仅当相关时);
- 本次对话内容。

我们承诺(与代码行为一致):

- **不会把整本书发给模型。** 每次请求携带的上下文总量有明确的预算上限,只包含少量必要的摘录,超出预算的内容会被截断;
- **不会发送与本次请求无关的历史。** 未经检索命中的旧反思、旧高亮不会被附带发送;
- 每次请求使用了哪些内容,你都可以在 App 内查看(反思证据与本地请求追踪);
- 请求从你的设备**直接发往该服务商**,不经过我们的任何服务器——我们也没有服务器。

**语音转写**使用 Apple 系统提供的语音识别能力完成,该过程受 Apple 隐私政策约束;App 中保留的是转写文本(以及你选择保存的原始音频文件,如有),同样仅存于本机。

## 四、我们不做的事

- 没有 ReadLoop 账号系统,不需要注册;
- 没有任何 ReadLoop 自有服务器接收你的数据;
- 不内置任何统计、遥测、广告或崩溃上报 SDK;
- 不收集设备标识用于追踪,不做跨 App 追踪;
- 不出售、不出租、不共享你的任何数据——因为我们根本接触不到它们;
- 不提供书城,不提供盗版书源;书籍只能由你自己导入(非 DRM EPUB)。

## 五、第三方 AI 服务商

当你使用 AI 功能时,发送给服务商的内容(见第三节)将受**该服务商自己的隐私政策与数据处理条款**约束,与我们无关。请阅读你所选服务商的隐私政策。

本 App 常见的服务商预设包括(你也可以使用任意 OpenAI 兼容地址):OpenAI、Anthropic、DeepSeek、Google Gemini、OpenRouter、Groq、Mistral、xAI、SiliconFlow(硅基流动)、Moonshot(月之暗面)、阿里云百炼、智谱。

更换服务商或删除 Key,不会丢失你本地的任何阅读数据与记忆。

## 六、你的数据控制权

在「设置 → 数据与隐私」中,你可以:

- **导出我的数据**:把你的全部个人数据(书籍、阅读位置、高亮、笔记、反思、长期记忆、「AI 眼中的我」画像等)导出为一个 JSON 文件自行保存或迁移。导出内容与你在 App 内看到的一致,**不包含**服务商配置与 API Key;
- **删除单本书**:删除该书及其进度、高亮、笔记、反思与索引;
- **清除所有本地数据**:两步确认后,删除全部书籍与文件、索引、进度、高亮、笔记、会话、反思、日志、记忆、成就、服务商配置、Keychain 中的 Key 以及本 App 的偏好设置,App 回到首次启动状态;
- **删除 App**:卸载即删除本机全部数据(钥匙串条目一并移除)。

你还可以随时在「My Mind」中查看、修改、删除 Agent 记忆,在设置中删除单个服务商配置。

## 七、儿童

本 App 不主动收集任何数据(如上所述,所有数据仅存于用户本机),因此不存在向儿童收集个人信息的行为。未成年人使用请由监护人知悉并同意。

## 八、政策的变更

如果我们未来引入任何会改变上述承诺的功能(例如可选云同步),我们会在实施前更新本政策,并在 App 内显著提示。当前版本:所有数据本地,无收集。
