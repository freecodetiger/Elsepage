# Voice Reflection 交付手测清单（2026-09-13）

> 自动化已覆盖状态机、源文本、音频文件生命周期、合并、恢复、导出和数据库提交。本清单只列必须由用户用 Xcode 真机完成的项。

## 1. 权限与失败恢复

- [ ] 首次点按麦克风，同时出现语音识别与麦克风权限提示
- [ ] 拒绝权限后仍可使用纯文字 Reflection，并看到可恢复文案
- [ ] 在系统设置重新授权后可再次录音
- [ ] 飞行模式下文字 Reflection 正常；语音失败不会丢已有文字

## 2. 转写与用户原文

- [ ] 长按开始录音、松手结束；点按也能开始/结束
- [ ] 录音期间可看到准实时 partial transcript
- [ ] 编辑转写后保存，重新打开内容等于用户编辑结果
- [ ] AI 优化后切回「我的原话」继续编辑，再保存，保存的是编辑后的原话
- [ ] 先语音、再清空全文、改纯文字保存，保存内容是新文字且不再标记语音
- [ ] 连续录第二段，前后文字都保留

## 3. 音频保存与播放

- [ ] 打开页面不会自动开麦；用户开始录音后默认保存音频
- [ ] 录音前关闭「保存音频」后，保存 Reflection 不产生音频文件
- [ ] 开启「保存音频」后录音，停止后编辑页立即出现音频管理器
- [ ] 保存 Reflection 后，会话页仍能看到同一个音频管理器
- [ ] 播放/暂停按钮状态正确，当前时间会推进，总时长正确
- [ ] 波形能区分静音与说话段，已播放部分有进度覆盖
- [ ] 点击或拖动波形可 seek；拖动前正在播放时松手后继续播放
- [ ] 菜单可“删除录音”且保留 Reflection 文字
- [ ] 杀掉并重开 App，录音仍可播放
- [ ] 连续录第二段并保存，播放的是一个合并后的完整音频
- [ ] 在已保存会话的追问输入框录音并发送，追问消息下出现独立音频管理器
- [ ] 追问音频可播放/暂停/seek，删除该追问后音频文件同步删除
- [ ] 录音结束后关闭「保存音频」，未提交草稿被清除
- [ ] 不保存直接退出 Reflection sheet，不留下可播放的草稿

## 4. 数据控制

- [ ] 删除整条 Reflection 后录音消失
- [ ] 删除书籍后该书录音消失
- [ ] 「清除所有本地数据」后录音目录为空，重启不恢复
- [ ] 导出 JSON 中用 Base64 包含已保存录音，可解码且不含 Provider/API Key

## 5. 中断与恢复

- [ ] 设置中关闭「默认保存录音」后，新 Reflection 默认不保存；重新开启后恢复
- [ ] 设置 → 数据与隐私显示录音段数和占用空间
- [ ] 「清理所有录音」删除全部音频，但保留 Reflection 文字
- [ ] 录音中进入后台，返回后可继续完成文字/保存
- [ ] 录音中强杀 App，重启后不残留草稿音频
- [ ] 提交 Reflection 后立刻强杀，重启文字、音频和 conversation 一致
- [ ] 删除操作中强杀，重启后数据库与音频文件不出现悬空引用
