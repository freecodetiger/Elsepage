# Reader Help 真机验收清单

> 状态：待用户执行
> 分支：`codex/reader-help-spec`
> 适用版本：包含 Reader Help 的 TestFlight / DEBUG 构建
> 前置：已配置可用的 BYOK Provider

## 0. 基础门禁

- [ ] `xcodegen generate` 后工程包含 `ReaderHelpModel.swift` 与 `ReaderHelpSheet.swift`
- [ ] App target 编译成功
- [ ] 打开一本已完成或可完成本地索引的 EPUB
- [ ] Provider 可用，或明确验证未配置时的降级行为

## 1. 选句入口

- [ ] 在正文中选中一句话
- [ ] 选区工具栏出现“问”
- [ ] 点击“问”后系统选区菜单关闭
- [ ] 立即出现轻量底部面板，不停留空白页
- [ ] 面板顶部显示正确选段

## 2. 一键解释

- [ ] 点击“解释这段”
- [ ] 面板立即进入准备/生成状态
- [ ] 回答出现在面板内
- [ ] 回答默认不长于 250 中文字左右
- [ ] 回答直接解释当前语境，而不是展开成通用文章
- [ ] 如果当前 Provider 为非流式，回答一次性出现；如果为 SSE，文本逐步出现

## 3. 具体问题与追问

- [ ] 在输入框输入具体问题并发送
- [ ] 回答和当前选段相关
- [ ] 在第一轮回答后继续追问
- [ ] 追问能理解上一轮上下文
- [ ] 连续追问不会把面板变成全屏聊天页
- [ ] 键盘弹出、输入、收起无异常跳动或内容回落

## 4. 上下文与防剧透

- [ ] 在章节中部选句提问，回答不会提到后续章节事实
- [ ] 在 retrieval child 的中间选句，当前段落可完整进入上下文
- [ ] 在当前 child 的精确边界选句，不会自动解锁下一 child
- [ ] 无 progression 的书/位置只基于可见选段回答，不进行全书检索
- [ ] 未完成索引时仍可使用可见文本，不出现“全书检索”行为
- [ ] 含 `textAfter` 的位置不会把下一段内容带入回答

## 5. 错误与取消

- [ ] 关闭面板会取消正在进行的请求
- [ ] 取消后不会继续刷新面板
- [ ] 网络/Provider 失败显示可重试状态
- [ ] 重试不会丢失当前选段
- [ ] 未配置 Provider 时阅读、翻页、进度、Highlight、Note 仍正常

## 6. 保存与生命周期

- [ ] 完成回答后可复制
- [ ] “存为笔记”成功后可在标注列表找到 Note
- [ ] 已关联 Highlight 时 Note 关联到对应 Highlight
- [ ] 没有 Highlight 时保存为独立 Note
- [ ] 同一回答不会重复生成 Note
- [ ] 保存失败时回答仍保留在面板
- [ ] 关闭再打开同一选段时，当前 ReaderScreen 内 thread 可恢复
- [ ] 切换另一句话时创建新 help thread
- [ ] 退出 Reader 后临时问答不再出现

## 7. 视觉与无障碍

- [ ] 浅色、深色、护眼主题下面板可读
- [ ] Dynamic Type 下选段、回答和输入区不互相遮挡
- [ ] VoiceOver 可读出选段、状态、回答、错误和保存结果
- [ ] 所有操作触控区域不小于 44pt
- [ ] 减少动态效果开启时面板仍可用

## 8. 性能记录

建议记录：

- 点击“问”到面板首帧的耗时
- 点击“解释”到首个可见文本的耗时
- 首 token 是否明显慢于预期
- 关闭面板到请求取消的耗时
- 键盘打开/收起的视觉稳定性

如发现回归，附：

- 机型
- iOS 版本
- Provider / 模型
- 是否流式
- DEBUG 日志中的 `readerHelp.*` 事件
