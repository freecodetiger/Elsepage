# 顶部标题行：大标题与玻璃胶囊同一行

2026-11-14。用户要求：删除书架左上两个按钮；把“书架”大标题上移，与右侧胶囊同一横列；“想法”“我的”同样处理。本轮已落到 App；阅读器未改。

## 结构

- 三个根页面隐藏系统导航栏，改用 `ElsepageRootHeader`：
  - 34pt 大标题在左（16pt 页边距）。
  - 右侧 44pt 高的玻璃胶囊放页面动作：书架是设置齿轮；想法是更多菜单（分组 / 设置）；我的是成就 + 设置两个图标。
  - 标题与胶囊在同一条 HStack 里垂直居中，标题不再占第二行。
- 标题行固定在内容上方，不随滚动收起；内容从标题行下方开始。
- 书架移除了排序与导入两个工具栏按钮。导入仍可通过底部玻璃加号或空书架按钮完成；排序入口本轮移除。
- 因为系统 `.searchable` 依附导航栏，书架与想法改用 `ElsepageSearchField`：36pt 高、10pt 圆角、tertiary fill、放大镜、清除按钮，Return 收起键盘。搜索过滤逻辑不变。
- 我的的分段控件仍在标题行下方；书架/想法的搜索栏在标题行与内容之间。

## 导航与详情

- 根页面 `.toolbar(.hidden, for: .navigationBar)`。
- “我的”的成就页与想法/问题详情显式 `.toolbar(.visible, for: .navigationBar)`，保留返回。
- 想法记录详情与阅读器继续隐藏导航栏，使用自己的返回方式。
- 设置、补写想法等 Sheet 不受影响。

## 兜底

| 条件 | 处理 |
| --- | --- |
| iOS 26 | 右侧胶囊用 `glassEffect` |
| iOS 18 | 同几何 `.ultraThinMaterial` + 描边 + 轻投影 |
| 减弱透明度 | 纯色 surface + 描边 |
| 键盘 | 搜索框聚焦时键盘通知让底部玻璃栏收起；Return 或清除后恢复 |
| 无障碍 | 标题带 header trait；动作按钮 44pt、有明确名称；搜索框有 label 与清除按钮 |

## 取舍

- 大标题不再随滚动折叠，标题行固定；这是“与胶囊同一行”的代价。
- 搜索从系统 `.searchable` 换成自绘字段，保留过滤/清除/Return，但没有系统搜索的建议与取消按钮。
- 书架的排序入口移除；导入保留在加号与空书架按钮。
- 书架移除了“继续阅读”区块标题：当前书行直接跟在搜索下方。这个标签既重复书名，又对“从未打开、只是最近导入”的书不准确；“补写想法”仍是行内的条件动作。若以后要保留这四个字，应把它和“补写想法”放进同一条 section header，而不是一个标题加一个行内浮层。
