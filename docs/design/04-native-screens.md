# 想法 / 我的 / 阅读：原生组件与密度

2026-11-14。书架收敛后，用户认为“我的”和“阅读”两页文字密度偏高，要求补充可复用组件、达到生产可读性，同时按奥卡姆剃刀只增加必要实体。本轮重做这两页；“想法”保留时间线结构，只共用字级与区段组件。未修改 App 实现。

[打开静态样张](../prototypes/elsepage-native-screens.html)。单文件、无 JavaScript、无网络请求；三帧 393×852，书名、记录、进度与封面均为演示数据。

问题不是“字太小”，而是三件事叠在一起：每行都套一张带描边的卡片、正文与辅助文字只差 2–3pt、分区之间没有容器。做法相应是：一个分区只加一个容器，拉开主次字级，给阅读页更大的字号、行距和底部余量。

## 组件库

只保留八个组件。每个都至少在两处使用，或承担唯一的阅读语义；没有单行卡片、没有装饰性胶囊。

| 组件 | 使用位置 | 规格 | SwiftUI 映射 |
| --- | --- | --- | --- |
| SectionHeader | 三页 | 20/600，尾部计数 13；上 32 / 下 10 | `Section` 的自定义 header，或分组前的 `HStack` |
| SurfaceGroup | 我的 | 每个分区一个白色容器；圆角 12；行内边距 16；1px 分隔线 | `List(.insetGrouped)` 的 section；或 `VStack(spacing:0)` + 表面背景 |
| ContentRow | 想法、我的 | 标题 17/600；可选摘要 15；可选元信息 13；内边距 16；可选小箭头 | `Button` + `.buttonStyle(.plain)` + `.contentShape(Rectangle())` |
| AccessoryRow | 我的 · 成就 | 38pt 图标底、标题 15/600、日期 13；不放简介 | `HStack(spacing: 12)`，整行合并无障碍 |
| MetricCard | 我的 · 连续记录 | 数字 28/700、单位 15/600、标签 13；1px 竖分隔；18/20 内边距 | 一个 `HStack` 放进卡片或 List 的一行 |
| ReaderChrome | 阅读 | 顶栏 56；底栏 56 + 安全区；材质背景；44pt 触达 | `overlay` 的上下两条 `VStack`，随轻点淡入淡出 |
| QuoteBlock | 阅读 | 18/1.8；左缩进 16；2px 左侧细线 | `Text` 容器加 padding 与左侧 overlay；正式实现放在阅读主题 CSS |
| Highlight | 阅读 | 黄色 32% 透明；圆角 2 | 现有高亮色；`AttributedString` 或 Readium decoration |

使用边界：

- 一个分区只加一个容器，绝不为每一行加卡片。
- 状态、来源、置信度、数量都用 13pt 辅助文字，不再做成彩色胶囊。
- 条件内容放在固定高度的标题行里（计数、`全部`），或改成单行空状态；不放在内容底部，避免高度跳动。
- 内容行（想法）不用小箭头；会进入详情或展开的行（我的）才用。
- 不新增颜色、字体或自绘控件；白色容器是唯一新增的表面。
- 全局破坏性操作（清除全部记忆）移出工具栏，放进菜单或设置。

## 我的

阅读顺序：连续记录 → 正在形成的看法 → 还在想的问题 → AI 记住的我 → 成就。

- 顶部只保留一张 `MetricCard`：7 天 / 3 天，数字 28/700，标签 13。原来的两个描边胶囊删除。
- 每个分区一张 `SurfaceGroup`，行内 16pt 内边距，行间 1px 分隔；不再给每行套 12pt 圆角描边卡片。
- 看法与问题：标题 17/600，摘要 15/400，元信息 13/400；阶段从彩色胶囊改为“稳定 · 11 月 12 日”这样的纯文字。
- 记忆：内容 15/400，元信息 13/400；“AI 推断 / 用户明确表达 / 置信度”不再用徽章，展开后才出现操作与依据。
- 成就：图标 + 标题 + 日期，删除宣传式简介；不再单独描边。
- 工具栏只保留设置；`清除全部记忆` 移到“记忆”分区的菜单或设置页。
- 页边距 20 → 16；分区之间 28 → 32；计数 13pt 固定在标题行尾，不改变高度。

SwiftUI 落点：优先 `List(.insetGrouped)`，让系统画分区容器、分隔线和滚动边缘；自定义 header 用 `SectionHeader`，行内边距 16。若继续用 `ScrollView + LazyVStack`，每个分区只放一个 `SurfaceGroup`，把 `BrainItemRow` / `MemoryRow` / `badgeRow` 现有的 `background + overlay` 移除。展开状态保留现有操作，用 `.bordered` 小按钮与 44pt 命中区域，不新增组件。

## 阅读

- 正文 20pt、行高 1.85（37pt），页边距 24，段间距 24；底部留 24pt 再进入底栏。
- 章节标题 28/600 宋体，章节标签 13/600 无衬线；顶栏书名 17/600，章节 13。
- 引文成为 `QuoteBlock`：18/1.8，左缩进 16，2px 左侧细线；不再用正文段落冒充引文。
- 重点句保留一处黄色高亮（32%），圆角 2；高亮色沿用现有标注色。
- 顶栏：返回、书名/章节、搜索、aA；底栏：2pt 进度线、目录、标注、62%、读到这里；图标 44pt 触达，无圆形底板。
- 样张展示一个章节开页（3 段正文 + 1 段引文）；真实分页仍由 Readium 决定，不按浏览器高度裁切。

SwiftUI / Readium 落点：正文大小与行高对应 `ReaderPreferences.fontSize`、`lineHeight`、`pageMargins` 的乘数，不把 20pt 硬编码进 chrome；引文与高亮属于阅读主题 CSS 与 Readium decoration。顶栏与底栏用 `.ultraThinMaterial`，轻点正文切换显隐，减少动态效果时不加过渡。

## 想法

保留现有的时间线，不加分区卡片：月份标题已经完成分组，再加一层容器是重复实体。

- 月标题 20/600，尾部条数 13；页边距 16。
- `ContentRow` 的摘要变体：书名 13/600 + 日期 13/400；摘要 17/600，最多两行；行间 1px 分隔，无卡片边框与小箭头。
- 搜索、分组菜单、设置入口不变。

## 状态与边界

- 空分区：一行 15pt 辅助文字，高度固定；不画空卡片。
- 计数与“全部”：放在固定的 `SectionHeader` 尾部；不在内容末尾追加按钮，避免出现/消失时推动页面。
- 未覆盖：补写想法 Sheet、设置、首启、想法/看法详情、标注菜单。这些页面继续使用现有结构，下一批再收敛。
