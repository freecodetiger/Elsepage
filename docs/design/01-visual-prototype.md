# 视觉方向原型 v0

2026-11-14。用户在产品理解之后明确授权 UI 重新设计与原型制作。本次交付是可丢弃的视觉探索，用来确认风格和交互方向；未修改 App 实现，也不构成已选定的生产设计规格。

## 打开与操作

[打开独立原型](../prototypes/elsepage-modern-prototype.html)。单个 HTML 文件，可直接用浏览器打开；无构建、依赖安装或服务器。也可通过 T3 对话中的交互原型查看。

底部 A/B/C 或左右箭头切换视觉方向；键盘左右方向键也可切换，在输入框内不会抢占光标操作。URL 参数 `?variant=A`、`B`、`C` 可固定初始方向。它不参与 App 构建。

| 方向 | 结构与视觉 | 适用取舍 |
| --- | --- | --- |
| A 纸间 · 首选建议 | 纸色、低饱和森林绿、衬线标题；当前书横向展开，其他书以三列封面展示 | 给书和阅读状态留出空间，兼顾阅读与表达，文学气质较强 |
| B 清晰 | 白底、黑灰、原生风格字体；紧凑当前阅读分区与平面书籍列表 | 扫读和较大书库更直接，装饰更少，情绪表达较弱 |
| C 夜航 | 墨绿、暖灰和少量琥珀色；当前书居中，其他书横向收纳 | 更沉浸、更聚焦当前书，可见书籍密度较低 |

三个方向改变了布局、信息顺序和视觉密度，并非只换颜色。原型外侧的说明和方向切换器属于评审工具，不是建议加入 App 的功能。

## 可体验的路径

- 书架：有书/空书架、搜索/无结果、排序、导入演示书籍。
- 阅读：打开演示章节、目录、阅读底色和字号；轻触正文中间段落展示选区操作。
- 批注：划线、取消划线、独立非空笔记、查看批注；笔记保存不移除划线。
- 阅读中的问答：固定演示回应、演示原文回跳、保存为演示笔记。
- Reflection：空白不可保存、输入原话、保存在本次页面内存中、进入阅读记录；后续追问以独立消息保留，不改最初原话。
- 想法：按时间/按书籍排序、记录详情、原话/AI回应的视觉区分、演示来源返回。
- 我的与设置：阅读/思考连续天数、看法/问题/记忆详情与来源、成就、身份预览、模型配置状态、隐私和演示导出预览。

## 实现边界与状态

**Implemented（仅指此 HTML 原型）**：以上内存交互、三种视觉方向、单文件离线运行、输入转义、减少动态效果支持。

**Partial**：正文只提供一段固定的选择演示；笔记/划线状态用于观察表面交互，不模拟完整 Locator/Range 多书持久化；目录与正文不代表真实 EPUB 引擎；原型的分组、设置和响应状态也不等同正式业务功能的完整覆盖。

**Planned / 待选方向**：当前书的独立视觉分区、排版、色彩、导航样式、Sheet与消息层级都是提案，尚未由用户选定或写入生产 UI 规格。

**Unknown / 未验证**：SwiftUI/Readium 中的落地效果、真实键盘/VoiceOver/动态字号、长书性能、真实模型回应/引用准确性、磁盘恢复。不得用浏览器原型证明原生 App 验收通过。

没有增加云同步、思想图谱或备份还原；没有把不可达的 Brain“继续想想”、Journal 编辑器接成已交付功能。录音与转写只展示已有能力的入口说明，不申请麦克风；模型配置不接受密钥，不发出网络请求。所有书目、作者、段落、进度、记忆与 AI 文案都是明确标注的虚构演示数据，非真实书籍引文或用户档案。

## 设计约束

保留书架/想法/我的三 Tab 与“读 → 表达 → 回看”的核心路径。当前阅读与补写想法同时可见；原话和派生回应分层；笔记与划线分开；来源有明确入口。推荐先讨论 A 的整体气质，再根据 B 的信息密度和 C 的沉浸感取舍。尚无用户选中方向，原型不应直接晋升为生产代码。

封面为本次原型编写的虚构书籍排版与几何图形。使用仓库真实 `docs/assets/branding/logo-vector.svg` 作为品牌素材；在嵌入副本中补充 viewBox 供缩放，未修改原资产。无远程字体、图片或第三方运行库；字体使用本机中文字体栈，不同平台字形会略有差异。
