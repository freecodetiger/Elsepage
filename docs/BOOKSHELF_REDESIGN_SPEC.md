# 页外书架重做 UI Spec

**状态：** Locked  
**日期：** 2026-09-14  
**范围：** 书架页视觉、信息架构、物理感交互、响应式与无障碍  
**不包含：** 数据模型迁移、Reader 渲染引擎、云同步、真实拖拽排序

---

## 1. 目标

把书架从“两列封面网格”改成有阅读现场感的个人书架：

1. 当前阅读永远是第一视觉层级。
2. 其他书籍以高密度、实体书架感的书脊或封面组织。
3. 用户能感受到抽取、抬起、吸附和放回的物理反馈。
4. 颜色不再被强制限制为黑白灰，但必须保持克制且有语义。
5. 书架仍保留搜索、排序、导入和书籍详情能力。
6. 待补写 Reflection 仍然在书架顶部出现，不因为删除 Today Tab 而丢失。

---

## 2. 已确认决策

### 2.1 结构

- 顶部：当前阅读桌面。
- 下方：实体书架与全部书籍。
- 不再恢复独立 Today Tab。
- 书架承担 Next Action 的唯一入口。

### 2.2 书籍形态

- 当前阅读：完整封面。
- 其他书籍：默认书脊优先。
- 点击或抽出后显示完整封面。
- 提供封面模式作为辅助视图，不作为唯一视图。

### 2.3 物理交互强度

- 按压缩放。
- 抬起阴影。
- 抽出位移。
- 松手吸附。
- 关键节点 Haptic。
- 不做陀螺仪、倾斜视差、持续漂浮或复杂 3D。

### 2.4 信息密度

- 只有当前阅读显示章节、进度、上次阅读时间。
- 其他书籍默认只显示书名和作者。
- 统计、标注数量、操作进入详情或上下文菜单。

### 2.5 色彩

- 应用壳层保持低噪中性基底。
- 封面、阅读进度和对象状态可以使用彩色。
- 不再要求应用壳层必须黑白。
- 品牌色、交互色和状态色继续语义分离。
- 阅读器纸张、暖色和深色主题仍保持独立。

---

## 3. 核心视觉概念

### 3.1 Physical Minimalism

不是木质拟物，也不是普通卡片网格。

视觉参考：

- Apple Books 的层次与“继续阅读”优先。
- 微信读书对中文阅读用户熟悉的书架结构。
- Delicious Library 的实体书对象感。
- Things 3 的触感和弹性，而非其视觉外观。
- Readwise Reader 的信息克制。

禁止：

- 木纹贴图。
- 3D 渲染材质。
- 持续漂浮。
- 每个书脊使用不同装饰纹理。
- 用彩色渐变代替层级。

### 3.2 阅读桌面

当前阅读以“固定书籍舞台 + 信息列”形成层级，不绘制额外桌面载体：

- 当前书只在顶部出现一次，不再重复出现在下方书架；搜索时仍可检索全部书籍。
- 不绘制木纹、圆角卡片、局部小矩形或独立桌面材质；空间关系由留白、固定几何和轻阴影表达。
- 当前封面与书架书脊使用同一物理对象高度，只改变正面/侧面宽度，不改变书籍尺度。
- 桌面几何不随书名、作者或封面来源比例变化：书籍舞台、信息列和操作位置保持一致。
- 封面外框必须与真实封面使用完全相同的 `100 × 150pt` 尺寸，不增加页芯、底板或额外投影层。
- 标题固定两行槽位并按尾部截断；作者、进度和日期各保留固定一行。
- 普通字号下两个操作并排且等宽；只有设备宽度不足或 Accessibility 字号才切换为纵向排布，切换条件不得依赖内容长度。
- 封面完整，仅使用组件自身的轻投影表达物体边界。
- 封面不叠加书签、角标或装饰性进度标记；进度只在信息区明确表达。
- 如果 Reflection 未完成，“补写想法”与“继续阅读”放在同一动作组，使用同级按钮样式和尺寸。
- 封面保持为纯粹的书籍对象，不叠加便签或次操作。
- 点击封面或“继续阅读”进入阅读器。
- 点击“补写想法”进入 Reflection 补写。

### 3.3 实体书架

书脊书架只提供“架子”和“书”的关系：

- 书架本体由一条基线或轻微承托阴影表达。
- 不画明显木质纹理。
- 书可以相对基线有 1–3pt 的高度差。
- 被选中的书可以短暂抽出，显示封面与标题。
- 行与行之间保持呼吸，不堆成密集列表。

## 4. 页面信息架构

```text
书架
├── 工具栏：搜索 / 排序 / 导入 / 设置
├── 当前阅读桌面
│   ├── 当前书封面
│   ├── 书名与作者
│   ├── 章节 / 进度 / 上次阅读
│   └── 继续阅读 / 补写想法（同级）
└── 全部书籍
    ├── 封面 / 书脊视图切换
    └── 可分组的实体书架
```

### 4.1 Next Action

优先级：

1. 存在未完成 Reflection：“补写想法”与“继续阅读”同级展示，不改变继续阅读可用性。
2. 不存在未完成 Reflection：主操作为“继续阅读”。
3. 没有正在读的书：桌面替换为“选择一本书开始阅读”。
4. 书架为空：使用现有空书架引导，不显示桌面。

### 4.2 全部书籍

默认使用实体书架：

- 每行显示 4–6 个书脊，按屏幕宽度决定。
- 每行底部有一条细承托线或阴影。
- 行与行垂直滚动。
- 书籍数量多时使用分页式书架行，不一次铺满所有封面。

封面模式：

- 保留两列封面网格。
- 适合用户快速按封面识别。
- 工具栏菜单中可切换。
- Dynamic Type accessibility size 下默认使用列表或单列封面，不使用书脊。

## 5. 书籍对象

### 5.1 当前阅读

显示：

- 完整封面
- 书名
- 作者
- 当前章节或位置
- 阅读进度
- 上次阅读时间
- 继续阅读
- 待补写 Reflection 时，与继续阅读同级的“补写想法”

### 5.2 书脊

显示：

- 纵向中文书名
- 作者，空间足够时显示
- 书籍颜色
- 可选进度细线

书脊参数：

- 宽度：32–44pt
- 高度：按封面 2:3 比例
- 圆角：2–4pt
- 书脊底部与书架基线对齐
- 书脊颜色从封面主色提取；失败时用书籍 ID 生成稳定中性色

### 5.3 封面

封面是主要识别资源：

- 保持原始比例。
- 不强制去色。
- 不从封面中提取颜色覆盖整个页面。
- 仅在书脊和进度上使用封面衍生色。

---

## 6. 物理交互

### 6.1 打开

- 用户轻点书脊或封面；松手即触发 Haptic 和导航，不插入固定等待。
- 使用 iOS 18 原生 `matchedTransitionSource` + `navigationTransition(.zoom)`，让被打开的书成为连续移动的视觉主体。
- 书脊模式允许系统 zoom 从窄书脊开始；封面模式和当前阅读桌面从完整封面开始。
- Reader 准备期间显示纸张底色与书封占位，EPUB ready 后与正文交叉淡入，不跳回空白加载页。
- zoom source 与 Reader 占位使用同一个 `100 × 150pt` 封面 frame；真实视图与 transition snapshot 必须使用相同的圆角和阴影参数，返回书架时不得出现尺寸跳变或阴影晚出现。
- 总感知时长控制在 280–360ms；EPUB 解析不得阻塞转场开始。
- Reduce Motion 下不执行 zoom，直接进入 Reader。

### 6.2 当前阅读

- 点击封面或“继续阅读”进入阅读器。
- 进度通过信息区的进度条与百分比表达，不在封面上叠加书签。
- 待补写 Reflection 时，“补写想法”与“继续阅读”同级展示。

### 6.3 书架

- 水平拖动用于浏览当前书架行。
- 垂直拖动用于滚动书架行。
- 首版不实现拖拽排序。
- 长按书籍显示上下文菜单：
  - 打开
  - 查看详情
  - 从书架移除

### 6.4 Haptic

建议触发：

- 书被抽出。
- 书回到书架并吸附。
- 当前阅读切换。
- “补写想法”被打开。

不建议：

- 每次滚动触发。
- 每一次列表进入触发。
- 高频、连续震动。

### 6.5 Motion

允许：

- spring 回弹
- 轻微阴影变化
- matched geometry 过渡
- 抽出和放回

禁止：

- 持续漂浮
- 倾斜感应
- 自动旋转
- 阅读内容动画

---

## 7. 色彩与材料

### 7.1 中性基底

应用壳层仍保持低噪：

- 页面背景：低饱和中性色
- 脚手架和菜单：中性色
- 边框和分割线：中性色

### 7.2 内容颜色

颜色主要来自：

- 封面
- 书脊衍生色
- 进度
- 当前阅读状态
- 成功 / 警告 / 危险语义色
- 阅读器主题

不再强制：

- background 必须是灰色
- surface 必须是白色/黑色
- brand 和 interactive 必须中性
- 所有 chrome token 的 RGB 必须相等

### 7.3 使用规则

- 彩色只用于强调、状态和识别。
- 一个页面保留一个主强调色。
- 状态色不得同时承担品牌色。
- 文本对比度继续满足 WCAG AA 4.5:1。
- 封面颜色最多影响书脊和局部进度，不覆盖整页。

---

## 8. 数据映射

### 8.1 当前书

优先级：

1. `LibraryNextActionModel` 指向的当前书。
2. 最近打开的、有阅读进度的书。
3. 最近导入的书。
4. 无书时返回空状态。

### 8.2 待补写状态

复用：

- `TodayProductStateResolver`
- `ReflectionPromptDismissalStore`
- `LibraryNextActionModel`

不恢复 Today Tab。

### 8.3 书籍状态

首版只区分：

- 正在阅读
- 其他书籍

不推断“读完”状态。除非用户未来显式标记，否则不得仅因为进度接近 1 就显示“已读完”。

---

## 9. 响应式与无障碍

- accessibility Dynamic Type：默认切换为单列列表，不显示书脊。
- VoiceOver：每本书读取书名、作者、进度和状态。
- 书脊模式必须提供可点击的 44pt 最小命中区域。
- Reduce Motion：关闭抽出、回弹和阴影动画。
- 物理交互不能是打开书籍的唯一方式。
- 用户可始终通过普通按钮或列表访问阅读器。
- 不依赖倾斜、陀螺仪或精确拖拽完成核心操作。

---

## 10. 性能约束

- 书籍封面和书脊颜色必须缓存。
- 书架行使用 Lazy 布局。
- 不因手势每一帧重新解析 EPUB。
- 不在主线程做封面解码。
- 书脊颜色提取失败时立即使用稳定 fallback，不阻塞列表。
- 物理动画不得影响打开阅读器的响应时间。

---

## 11. 组件边界

建议新增：

- `LibraryShelfLayout`
  - 计算每行书脊数量、书脊宽度、行高。
- `LibraryCurrentReadingDesk`
  - 当前书、进度、Next Action。
- `LibraryShelfView`
  - 书脊书架、分组、滚动。
- `BookSpineView`
  - 单本书脊。
- `BookInteractionState`
  - lifted / pulled / resting / opening。
- `LibraryShelfColor`
  - 封面颜色提取和 fallback。

复用：

- `LibraryModel`
- `LibraryNextActionModel`
- `ElsepageBookCover`
- `LibraryGridLayout`
- `ReaderScreen`

## 12. 分阶段实施

1. 更新设计 token 与测试，移除黑白硬约束。
2. 实现当前阅读桌面与现有 Next Action。
3. 实现纯静态书脊书架。
4. 加入按压、抬起、抽出、吸附与 Haptic。
5. 加入书脊/封面视图切换。
6. 完成 Dynamic Type、VoiceOver 和 Reduce Motion 回退。
7. 真机验收与性能采样。

---

## 13. 验收标准

- [ ] 书架顶部始终先呈现当前阅读或唯一 Next Action。
- [ ] 当前阅读显示封面、书名、作者、章节和进度。
- [ ] 当前书在桌面出现时不在下方书架重复展示。
- [ ] 当前封面与下方书脊共享同一对象高度。
- [ ] 桌面书本外框与真实封面尺寸完全一致，不出现额外页芯、底板或尺寸错位。
- [ ] 更换书籍不会改变桌面舞台、信息槽位或操作排列。
- [ ] 待补写入口与“继续阅读”同级，不叠加在封面上。
- [ ] 其他书籍默认以书脊呈现，密度高于当前封面网格。
- [ ] 轻点书籍有按压和 Haptic 反馈，并以连续 zoom 进入阅读器。
- [ ] Reader 准备期间不出现空白加载页或内容闪跳。
- [ ] Reader 返回书架时封面不改变尺寸，也不出现延迟阴影。
- [ ] Reduce Motion 下不丢功能。
- [ ] accessibility Dynamic Type 使用可读列表。
- [ ] 不再要求应用壳层所有 token 为中性色。
- [ ] 封面颜色可影响书脊和进度，但不能覆盖整页。
- [ ] 当前封面不显示抽象书签或角标。
- [ ] 不恢复 Today 独立 Tab。
- [ ] 不新增持久化迁移。
