# Quick Task 260914-x71: 想法页编辑式 HTML 原型

## 目标

创建独立新版原型，验证“编辑式记录流”是否比当前圆角卡片列表更适合「想法」页。

## 设计方向

- 没有重复卡片外壳，使用月份标题、留白和细分隔线组织内容。
- 概要成为视觉主角，书名与日期退为轻量上下文。
- 删除记录数量和行尾箭头。
- 搜索默认收起为工具栏图标，点击后在标题下方展开。
- 保留按时间 / 按书籍分组与设置菜单。
- 保留底部三 Tab 玻璃导航。
- 提供明暗主题切换、按压反馈和 Reduced Motion 回退。

## 任务

1. 在 `docs/prototypes/thoughts-editorial.html` 建立独立原型。
2. 使用本地无依赖 HTML/CSS/JS 完成可交互分组、搜索与主题切换。
3. 使用编辑器式中文排版，保持与页外中性壳层一致。
4. 使用浏览器截图检查首屏密度、换行和明暗模式。
