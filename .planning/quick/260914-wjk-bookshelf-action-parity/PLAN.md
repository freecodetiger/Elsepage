# Quick Task 260914-wjk: 书架桌面动作层级修正

## 目标

保留当前已经统一的书籍物理尺度与桌面承载场景，只调整待补写 Reflection 的操作层级。

## 任务

1. **移除封面便签**
   - 删除当前封面上的“补写想法”纸质便签。
   - 封面恢复为单纯的书籍对象，只负责进入阅读器。

2. **建立同级操作**
   - 在书名、作者、进度之后，让“补写想法”和“继续阅读”使用同一操作组。
   - 两者使用相同按钮样式、尺寸和强调级别。
   - 空间不足时允许操作组自然改为纵向排列。
   - 无待补写状态时只显示“继续阅读”。

3. **同步规范与验证**
   - 更新书架 spec：补写不再是封面便签，而是与继续阅读同级的动作。
   - 运行 Swift parse、diff check 与 swift test；完成后恢复 Package.resolved。
