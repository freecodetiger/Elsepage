# Quick Task 260914-wpb: 固定阅读桌面排布

## 目标

让书架顶部桌面成为固定舞台：换书只替换内容，不改变书籍区、信息区、桌面高度或操作位置。

## 任务

1. **移除内容驱动布局**
   - 当前 `ViewThatFits` 会因标题理想宽度决定横/纵布局，改为固定尺寸候选。
   - 常规字号下使用固定横向舞台；窄屏或 Accessibility 字号使用确定性纵向舞台。
   - 布局分支只取决于容器宽度与 Dynamic Type，不取决于书名。

2. **建立固定信息槽位**
   - 标题固定两行高度，超长标题截断。
   - 作者固定一行，缺失时显示“未知作者”。
   - 进度与日期固定一行高度。
   - 操作区固定排列；常规字号始终横排，Accessibility 字号纵排。
   - 两个动作按钮等宽，位置不随内容变化。

3. **保持书籍舞台固定**
   - 封面、桌面平面、接触阴影保持现有固定尺寸。
   - 不拉伸或裁掉封面外框；不同来源封面只在固定框内裁切。

4. **同步规范与验证**
   - 写明桌面几何不随书名、作者或封面比例变化。
   - 运行 Swift parse、diff check 与 swift test；完成后恢复 Package.resolved。
