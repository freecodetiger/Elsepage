# Quick Task 260914-wt4: 现代拟物书架重构

## 目标

把书架从“局部桌面矩形 + 中性书脊网格”升级成有真实家具结构的现代拟物：
上方是宽大的木质阅读桌面，书本平放；下方是带完整木质承托板的书柜。

## 设计边界

- 结构拟物、材质拟物，排版与交互保持现代，不回退到旧式拟物。
- 木纹克制、低对比、程序化生成，不引入大图或重依赖。
- 明暗模式均使用可读的胡桃木材质；导航、菜单等数字 Shell 保持不变。
- 保留固定桌面几何、书籍尺度、zoom transition 与 Reduce Motion 回退。

## 任务

1. **更新 Source of Truth**
   - 修改 PRD §10.1 与 §21.9，允许书架使用现代家具感材质。
   - 更新 UI Language spec 和 Bookshelf spec，移除“禁止木纹”旧约束。

2. **实现共享木质材料**
   - 在现有书架文件中增加程序化 `LibraryWoodSurface`。
   - 支持桌面 / 书架两种厚度与圆角。
   - 使用低对比木纹、前缘和明暗模式颜色。

3. **重构阅读桌面**
   - 桌面铺满书架内容宽度，不再使用局部小矩形。
   - 书封固定尺寸，增加页芯厚度、接触阴影，形成平放物体。
   - 信息槽位保持固定；文字、进度与按钮适配木材对比度。

4. **重构实体书柜**
   - 默认书脊模式按设备宽度选择固定列数。
   - 每排共享完整木质承托板，移除每本书各自的短横线。
   - 保留按压、Haptic、zoom transition 与封面模式。

5. **验证**
   - 更新 Spec 验收项。
   - 运行 Swift parse、diff check 与 swift test；完成后恢复 Package.resolved。
