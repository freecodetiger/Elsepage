# Quick Task 260914-wqp: 删除封面抽象进度书签

## 目标

删除当前阅读封面右侧仅露出一点的进度书签，避免用户误以为它是可操作对象或页面外露。

## 任务

1. **删除封面书签**
   - 移除当前桌面封面中的彩色 Capsule 进度标记。
   - 保留文字区进度条与百分比，作为唯一、明确的进度表达。
   - 封面恢复为纯书籍对象，不再承载装饰或状态。

2. **同步规范**
   - 删除书架 spec 中“书签从书页露出”和“拖动书签”等剩余描述。
   - 将 Reflection 入口相关旧表述统一为与“继续阅读”同级的“补写想法”。

3. **验证**
   - 运行 Swift parse、diff check 与 swift test；完成后恢复 Package.resolved。
