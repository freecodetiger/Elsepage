# Quick Task 260914-wxe: 撤回木质拟物并修正书本尺寸

## 目标

撤回真实界面中突兀的木质桌面和木质承托板，恢复到低噪中性书架，同时保证桌面书本外框、页芯和封面使用同一尺寸。

## 任务

1. **撤回木质视觉**
   - 删除程序化木纹 Surface、木质桌面背景和木质书架承托板。
   - 恢复中性书脊网格与简洁承托线。
   - PRD 与 UI/Spec 恢复“应用壳层低噪中性”的约束。

2. **修正桌面书本对象**
   - 移除封面下方额外的页芯层和脱离封面的投影。
   - 桌面上只使用封面本身的固定 `100 × 150pt` 外框。
   - 保持封面、书脊和 Reader zoom source 使用同一对象尺寸。

3. **保留有效改进**
   - 保留固定桌面几何、固定信息槽位和同级操作。
   - 保留连续 zoom transition、删除抽象书签和 Reduce Motion 回退。

4. **验证**
   - 运行 Swift parse、diff check 与 swift test；完成后恢复 Package.resolved。
