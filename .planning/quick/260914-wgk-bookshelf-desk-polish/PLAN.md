# Quick Task 260914-wgk: 书架桌面视觉与比例修正

## 目标

修正书架顶部的三层问题：桌面像卡片、当前书与书架书脊尺度不一致、待补写入口像独立追加卡片。

## 任务

1. **统一书籍物理尺度**
   - 当前阅读封面与书架书脊使用同一对象高度。
   - 当前书在桌面出现时，不再重复出现在下方书架。
   - 搜索状态仍可检索到全部书籍。

2. **把阅读桌面还原为承载场景**
   - 移除当前阅读区块的圆角卡片外框。
   - 用很浅的桌面平面、前缘和接触阴影表达“书放在桌面上”。
   - 保留封面、书名、作者、进度、上次阅读与继续阅读。

3. **把补写变成封面上的便签**
   - Reflection 待补写状态改为贴在当前封面上的窄便签。
   - 便签是主入口，继续阅读仍保持可用。
   - 不新增独立卡片或新的数据模型。

4. **同步规范与验证**
   - 在书架 spec 中明确当前书不重复展示、桌面不是 card、补写为封面便签。
   - 运行 Swift parse 与 swift test；完成后恢复 Package.resolved。
